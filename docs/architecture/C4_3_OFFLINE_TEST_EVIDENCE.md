# C4.3 Offline Test Evidence

We cannot build the real Fabric mod or open a Minecraft world in this environment because the repository is accessible read-only through GitHub and the full local project checkout is not present. A compact synthetic **248 physical site** fixture was created to test the *new Python pipeline*, containing two 550/2,100-person populated pilots and 246 zero-population placeholders. It is explicitly NOT the real C1 248-site dataset.

The following ran successfully:

- Python `py_compile` for all supplied tools.
- Catalog mapping checks: 206 workbook rows, 204 distinct IDs; source repeats retained and disabled as duplicate employment proposals.
- Synthetic full-site job allocation: positive worker totals preserved, vacant sites empty, proposed workplace counts calculated.
- Architectural JSON upgrade: 43 to 61 generic C3 template definitions.
- Exact-match patching of synthetic C3/C2 Java guard excerpts (not Java compilation).
- Two-site full-demand layout generator: no plot overlaps, no road intersections (planner raises on overlap), stable explicit pilot IDs, **110 and 219 planned homes**, multiple expanded field parcels, and output valid JSON.

The result under the synthetic fixture was approximately 280 plotted lots / 1,450 indexed chunks at Ramsgate and 786 plotted lots / 4,355 indexed chunks at Acorn Hall. These depend on **synthetic** sector percentages and are not guaranteed counts for your actual canonical input: run your local review scripts for authoritative current estimates.

Not tested here:

- Actual local repository C1 JSON of ~7.7 MB and C4.2 Java source compilation with the proposed data.
- Runtime C3/C2 building generation, in-game site terrain surveys and performance stress test.
- Persistent NPC assignments, employment/labor economy, or save/load migration.
- World-wide MAJOR sites or Winterfell layout replacement (deliberately not changed).
