# Batch 19.0E.1 — Global Holdings Audit

Generated against the 298 AC scenario dynasty catalog after the global holdings expansion.

## Audit rules

- **No holdings found**: the dynasty exists in the scenario, but no sufficiently supported named holding/seat was found or authored.
- **Family never had a Holding**: reserved only for cases where the available sources affirmatively establish a non-landed lineage. Absence of a named seat is **not** enough. No unresolved dynasty currently meets that standard with enough confidence, so these sections are intentionally empty.
- **House doesn't exist in scenario**: the dynasty catalog marks the line extinct, not yet founded, unknown/inactive, or otherwise inactive at scenario start.
- This audit is against **our scenario catalog**, not every family ever mentioned in all ASOIAF media.
- Sothoryos and Ulthos currently have no dynasty entries in the scenario catalog, so there is nothing to classify there yet.
